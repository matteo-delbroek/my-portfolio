My electronics journey

when I wass 12 I read a book about Scrath

It all started on Scratch, where I first discovered the micro:bit. Not long after, I joined CoderDojo and quickly fell in love with programming it. On the micro:bit website, I noticed you could code it using Python or JavaScript. I had no idea what those were, only that they were more powerful than block-based coding. After asking an AI whether to start with Python or JavaScript, I chose Python—and even built desktop apps using Tkinter.
From there, I moved on to web development with HTML and CSS, though I put that on pause when I got an ESP32 for my birthday. I started building projects with my old micro:bit sensors, and after realizing not all of them were compatible, I bought a full starter kit that I still use today. More recently, I picked up an Arduino UNO R4 Minima to build new electronics projects. Alongside coding and hardware, I also own a Bambu Lab P1S 3D printer and enjoy designing custom parts in Autodesk Fusion—I'm not a CAD pro yet, but I'm getting better with every print.
