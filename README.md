# Matteo Delbroek — Personal Portfolio

Welcome to the repository for my first personal website! I built this page from scratch using HTML and Tailwind CSS to share a bit about who I am and what I love creating.

## What's Inside
* **About Me:** A short introduction to my life and passion for breakdancing.
* **My Programming & Electronics Journey:** The story of how I went from block-based coding in Scratch to writing Python, building desktop apps with Tkinter, diving into HTML & CSS, and tinkering with hardware like the micro:bit, ESP32, and Arduino UNO R4 Minima.
* **3D Printing & CAD:** A glimpse into my projects with my Bambu Lab P1S 3D printer and custom designs in Autodesk Fusion.

## Built With
* **HTML5**
* **Tailwind CSS** (via CDN)
